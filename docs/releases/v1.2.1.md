# Run Shelf 1.2.1

修复 1.2.0 对旧任务时区字段处理过严，导致包含历史 `timezone: "UTC"` 的任务无法保存的问题。

旧版 Run Shelf 实际一直使用 Mac 本机时区计算 Cron；1.2.1 会在读取旧 schemaVersion 1 任务时将历史非本地时区值规范化为 `local`，保持原有执行时间，并在下一次保存时写回真实语义。CLI 新建或更新任务时仍只接受 `timezone: "local"`，避免产生未实现的时区行为。

校验：

- 35 项测试通过，0 失败、0 跳过。
- 旧 UTC 任务加载、备注/脚本/计划保存、任务切换、重启持久化、手动运行与日志展示的隔离 UI 冒烟通过。
- App 与 CLI universal Debug 构建通过（arm64 + x86_64）。
- Xcode 静态分析通过。
- 发布产物使用 Developer ID 签名，提交 Apple 公证并 staple 后发布。
