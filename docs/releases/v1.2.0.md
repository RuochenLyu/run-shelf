# Run Shelf 1.2.0

本版本集中修复长期使用后任务切换变慢、历史与日志读取无上限，以及 App、CLI、后台调度器并发修改任务时的数据一致性问题。

主要变化：

- 将任务选择、磁盘监控和本地运行协调从 `TaskStore` 拆分，移除侧边栏切换路径中的同步磁盘扫描和不必要视图重建。
- 引入稳定的跨进程仓库锁与任务锁，防止重名创建、并发覆盖和任务删除后被旧运行重新创建。
- 严格执行 TaskSpec 与 UTF-8 文件契约，未知字段和不支持的时区会返回明确错误。
- 历史记录改为限量、增量读取；CLI 日志默认最多返回 1 MiB，并支持显式完整读取。
- 后台调度改为可选能力，未启用时仍可编辑、保存和手动运行任务。
- 降低运行状态轮询频率并增加调度日志轮转，减少空闲唤醒和长期磁盘增长。
- 补充并发、数据安全、CLI 端到端和 Runner/Scheduler 回归测试。
- 建立 Schema 生成检查、统一本地/CI 门禁和可验证的版本号映射。

校验：

- 34 项测试通过，0 失败、0 跳过。
- App 与 CLI universal Debug 构建通过（arm64 + x86_64）。
- Xcode 静态分析通过。
- 发布产物使用 Developer ID 签名，提交 Apple 公证并 staple 后发布。
