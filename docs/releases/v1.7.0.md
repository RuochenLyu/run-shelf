Run Shelf 1.7.0 支持把本地已有的脚本直接导入为任务。

主要变化：

- 新建任务表单新增「导入文件」卡片：点击选择文件，或把文件拖进表单。脚本内容会复制进任务的 `run.sh`，之后移动或修改原文件不影响任务；需要原地执行某个文件时，继续使用「项目脚本」模板。
- 解释器只按可靠信号决定：文件自带 shebang 时原样保留；没有时按扩展名补一行（`.sh` / `.bash` → bash，`.py` / `.js` / `.rb` / `.pl` 解析为绝对路径，其余为 zsh），并在表单里说明补了什么。不按脚本内容猜测语言。
- 导入时按后台实际使用的 PATH（`/usr/bin:/bin:/usr/sbin:/sbin`）检查解释器：`#!/usr/bin/env node` 这类在终端能跑、在 Run Shelf 里会找不到的写法，会在创建前给出建议的绝对路径；解析解释器时 Homebrew 优先于系统自带的 shim。
- 目录、管道、超过 128 KB、UTF-16、二进制、非 UTF-8 和空文件会被拒绝，并给出一句说明。

兼容性：

- 不改变任务格式、TaskSpec、CLI 或调度协议，已有任务不受影响。

校验：

- `scripts/check.sh` 通过，新增导入解析与端到端创建、运行测试。
- 新建任务表单的默认、已导入、出错和深色外观经离屏渲染检查。
- App 与发布产物通过签名、公证、staple 和完整性校验。
