# Run Shelf 1.3.0

重写 App 的任务刷新与日志展示链路，解决长时间运行后侧边栏切换变慢、内存持续增长，以及阅读历史日志时滚动位置跳动的问题。

- 无变化的磁盘扫描不再发布 SwiftUI 更新。
- 只有当前选中且正在运行的 run 会刷新日志；历史日志保持静止。
- 实时日志刷新不再替换滚动视图，相同内容不再触发重绘。
- 用轻量 tab 按钮替换会在频繁切换时积累观察对象的分段 Picker。
- 保持现有任务目录、schema、CLI、Runner 和 Scheduler 协议不变。

校验：

- 37 项测试通过，0 失败。
- App 与 CLI universal Debug 构建通过（arm64 + x86_64）。
- 隔离数据任务切换压力测试中，热切换稳定在 14–27 ms；多轮空闲扫描后关键 Observation 对象数量不增长。
- 发布产物使用 Developer ID 签名，提交 Apple 公证并 staple 后发布。
