Run Shelf 1.8.0 支持隐藏菜单栏图标，并修复关闭主窗口时 App 整个退出的问题。

主要变化：

- 设置 →「系统」新增「在菜单栏显示图标」开关，默认开启。关闭后菜单栏图标立即移除，无需重启；按住 ⌘ 把图标拖出菜单栏也会同步关闭这个开关。隐藏后通过 Dock 图标打开主窗口，后台调度不受影响。
- 修复关闭主窗口后 App 随之退出的问题：现在关窗口只关窗口，菜单栏入口和失败通知转投继续工作；点 Dock 图标或菜单栏「打开 Run Shelf」可重新打开主窗口。退出请用 ⌘Q 或菜单栏「退出 Run Shelf」。

兼容性：

- 不改变任务格式、TaskSpec、CLI 或调度协议，已有任务不受影响。

校验：

- `scripts/check.sh` 通过。
- 在菜单栏图标显示与隐藏两种状态下，实测设置开关实时增删菜单栏图标、关闭主窗口后进程保持运行、Dock 重新打开主窗口。
- App 与发布产物通过签名、公证、staple 和完整性校验。
