Run Shelf 1.5.1 简化侧边栏任务状态，让运行健康与下一次调度更容易快速判断。

主要变化：

- 正常任务显示下一次运行时间，并用单一的绿色行尾图标表示最近运行成功。
- 运行中任务显示系统强调色进度指示和持续时间。
- 失败、超时、跳过、取消、计划异常和停用状态使用各自明确的图标与文案。
- 每行最多显示一个状态图标，避免同时展示当前状态与历史状态造成混淆。
- 成功图标的悬停提示和辅助功能标签包含完整的上次运行语义与时间。
- 计划无效状态优先于历史运行结果，避免把不可调度任务显示为健康。

校验：

- `scripts/check.sh` 通过。
- 使用隔离任务目录完成真实 App 侧边栏布局、状态颜色和停用状态检查。
